## 🛠 Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5      | Structure & semantic markup |
| CSS3       | Styling, layout, responsive design |
| JavaScript (ES6+) | Interactivity, theme toggle, form validation |
| Google Fonts | Inter + Merriweather typefaces |

No frameworks, libraries or build tools are used. Pure HTML, CSS, and JavaScript.

---

## ✨ Features

- **Responsive design** – works on desktop, tablet and mobile
- **Dark / Light mode toggle** – preference saved in `localStorage`
- **Active section highlight** – navigation updates as you scroll
- **Mobile hamburger menu** – accessible collapsible nav
- **Smooth scrolling** – between all sections
- **Contact form with validation** – required fields, email format check, error/success feedback
- **Profile photo with fallback** – gracefully handles missing image
- **Semantic HTML** – proper landmark elements and aria attributes
- **Reduced-motion support** – respects `prefers-reduced-motion`

## 🚀 How to Run Locally

1. **Clone or download** this repository.
2. Place your profile photo at `assets/profile.jpg`.
3. Open `index.html` in any modern browser.

No server, build step or dependencies required.

```bash
# Optional: open with a local server for best results
npx serve .
# or
python3 -m http.server 8080
```

Then open `http://localhost:8080` in your browser.
